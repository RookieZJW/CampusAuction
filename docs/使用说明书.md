## 一、系统简介

「校园拍场」是一个面向校园场景的 C2C 在线拍卖平台。学生用户将闲置物品（教材、数码、生活用品等）发布为拍品，设置起拍价、加价幅度与拍卖时长；其他学生在倒计时内公开竞价，价高者得，线下当面交割。

**核心业务闭环**：发布拍品 → 管理员审核 → 拍卖开始 → 用户竞价 → 拍卖结束自动结算 → 生成订单 → 线下交割 → 互评完成。

**资金说明**：平台不涉及真实资金。系统采用「虚拟余额 + 保证金」机制——注册赠送虚拟余额 100 元，参与竞拍时冻结保证金（默认 10 元），违约扣除保证金与信用分。

## 二、用户使用手册（微信小程序端）

### 2.1 进入系统

1. 打开微信，搜索或扫码进入小程序「校园拍场」；
2. **老用户**（本地还存着登录态）直接静默进入上次的账号，不再弹登录框；
3. **新用户**（或登录态已失效）进入时自动弹出登录卡片。可点遮罩先关闭逛逛，但竞拍、发布等操作需要先登录。

### 2.2 登录（新用户一屏填齐）

1. 进入小程序弹出登录卡片（也可在「我的 → 去登录」重新打开）；
2. 在同一屏完成资料：
   - **头像**：点头像按钮，选微信头像或相册图片（可选，不影响登录）；
   - **昵称**：在输入框填写，可用微信昵称建议（必填）；
   - **手机号**：点「微信一键授权手机号」并确认（必填）；
3. 勾选《用户协议》与《隐私政策》；
4. 点「登录」：服务端用 `wx.login` 的 code 换 openid、用手机号授权 code 换号码，一步建号（新用户赠送虚拟余额 **100 元**、初始信用分 **100**），并把头像上传到服务器；
5. 登录成功后回到原页面，「我的」页立即显示真实头像、昵称和手机号。登录态有效期 7 天，过期后再次进入会自动补弹登录框。

> 微信规则：`wx.login` 只能拿到 openid，头像、昵称、手机号是三个独立授权动作，但都在登录这一屏完成，用户感知就是「登录时把资料填齐」。同一手机号在任何微信上登录都进入同一账号，出价、订单、钱包与信用分互通。系统不会默认勾选协议，也不会静默获取资料。

### 2.3 浏览拍卖

| 操作 | 说明 |
|---|---|
| 拍卖大厅 | 底部 Tab「拍场」；按**剩余时间从少到多**排序，制造紧迫感 |
| 分类筛选 | 顶部横滑分类条：全部 / 教材书籍 / 数码电子 / 生活用品 / 运动器材 / 服饰鞋包 / 乐器 / 其他 |
| 下拉刷新 | 首页下拉刷新最新列表 |
| 加载更多 | 列表滚动到底自动翻页 |
| 查看详情 | 点击任意卡片进入详情页 |

**拍卖卡片信息**：封面图、标题、分类与成色标签、当前价、出价次数、剩余时间倒计时（剩余 ≤5 分钟时倒计时变红加粗）。

### 2.4 拍品详情页

- **图集**：左右滑动查看，点击全屏预览；
- **价格区**：当前价、出价次数、起拍价、加价幅度、保证金金额；
- **倒计时**：每秒刷新；进入「最后 5 分钟」高亮预警；
- **出价记录**：显示最近 20 条出价（昵称脱敏显示，如「微\*\*户」）；
- **拍卖规则提示**：结尾前 5 分钟内有新出价将自动延长 2 分钟（最多 3 次），防止「压秒出价」。

### 2.5 发布拍品

入口：底部 Tab「发布」。

**第一步：填写基本信息**

| 字段 | 要求 |
|---|---|
| 标题 | 必填，≤100 字，如「考研数学复习全书」 |
| 分类 | 必选，8 个一级分类 |
| 成色 | 必选：全新 / 九成新 / 八成新 / 七成新 / 明显使用痕迹 |
| 描述 | 选填，≤2000 字，建议写明使用时长、瑕疵 |
| 图片 | 最多 3 张，自动压缩后上传 |

**第二步：设置拍卖规则**

| 字段 | 要求 | 说明 |
|---|---|---|
| 起拍价 | 必填，≥1 元 | 第一次出价必须达到的价 |
| 加价幅度 | 必填，≥0.1 元，默认 1 元 | 每次出价必须比当前价高出该值 |
| 拍卖时长 | 2 小时 / 6 小时 / 1 天 / 3 天 / 7 天 | **从管理员审核通过的时刻起算** |

**第三步：提交审核** → 拍品进入「待审核」状态，管理员通过后立即开拍。

**AI 定价建议（W5）**：填写完标题、分类、成色后，点击起拍价旁的「帮我估个价」：
- 系统调用大模型（DeepSeek）结合标题、分类、成色与描述给出建议起拍价区间与依据；
- 若 AI 服务未配置或暂时不可用，自动降级为规则估价（分类基准价 × 成色系数），卡片上会以「智能估价」徽标区分；
- 点击「用 X 元作起拍价」可一键填入，也可以忽略自行定价。

> 保证金说明：每场拍卖统一冻结 10 元虚拟保证金，未中标自动解冻；中标后违约（48 小时内未完成交割）将扣除保证金并扣减信用分。

### 2.6 我发布的（状态跟踪）

入口：「我的 → 我发布的」。

| 状态 | 含义 | 你能做什么 |
|---|---|---|
| 待审核 | 已提交，等待管理员处理 | 等待（通常 24 小时内） |
| 拍卖中 | 审核通过，正在进行 | 点进去看出价进展 |
| 已驳回 | 审核未通过（显示理由） | 修改后重新提交 |
| 已成交 | 有人中标，进入交割 | 联系买家约定面交 |
| 已流拍 | 到期无人出价 | 可调价重新发布 |
| 已取消 | 你或管理员取消 | — |

### 2.7 参与竞拍

1. 在详情页确认当前价与加价幅度；
2. 点击「我要出价」，输入出价金额（系统校验：≥ 当前价 + 加价幅度）；
3. 出价成功即冻结保证金 10 元，成为当前最高出价者；
4. 被他人超过时会收到提醒，可继续出价；
5. 拍卖结束后：
   - **中标**：生成订单，与卖家约定线下交割，完成后确认收货并互评；
   - **未中标**：保证金自动解冻。

**防狙击规则**：结束前 5 分钟内任何新出价，都会使拍卖结束时间自动延长 2 分钟（最多延长 3 次），保证所有人都有反应时间。

**信用分规则**：

| 行为 | 变动 |
|---|---|
| 正常完成一笔交易 | +2 |
| 中标后 48 小时未交割 | -10，并扣保证金 |
| 被举报且核实 | -20 |
| 信用分低于 60 | 限制出价与发布，需正常交易恢复 |

### 2.8 拍下之后：订单交割（W4 上线）

拍卖结束后，中标者与卖家都会收到站内通知，同时系统自动生成订单。

入口：「我的 → 我的订单」，页面分「我买到的」「我卖出的」两个 Tab。

| 步骤 | 买方（中标者） | 卖方 |
|---|---|---|
| 1. 查看订单 | 看到拍品、成交价、订单号、对手方昵称 | 同一订单，视角相反 |
| 2. 约定地点 | 点「约定交割地点」，填写如「图书馆一楼大厅」 | 收到通知后同样可见 |
| 3. 线下交割 | 当面验货、付款（平台仅记录虚拟保证金，不参与真实资金） | 交付拍品 |
| 4. 确认交割 | 点「确认交割完成」，订单置为已完成 | — |
| 5. 交易结算 | 冻结的 10 元保证金解冻退回，双方信用分 **+2** | 同 |
| 6. 超时未交割 | 48 小时内未确认，订单自动取消：**保证金没收 + 信用分 -10** | 拍品可重新发布 |

> 交割地点修改会对对手方产生通知；一旦确认交割，订单不可撤销。

### 2.9 钱包、信用与消息

| 页面 | 入口 | 内容 |
|---|---|---|
| 钱包流水 | 我的 → 钱包流水 | 虚拟余额（注册赠 100 元）+ 全部变动明细：注册赠送 / 保证金冻结 / 解冻 / 违约扣除 / 退款 |
| 信用分 | 我的 → 信用分 | 当前分数与等级（优秀 ≥90 / 良好 70-89 / 一般 60-69 / 受限 <60）+ 每一次加减分明细 |
| 消息中心 | 我的 → 消息中心 | 竞拍成交、拍品结拍、被超越、审核结果四类通知；支持单条已读、全部已读、下拉刷新；点击可跳转对应拍品 |

> 「我的」页的消息入口会显示未读条数，未读数在进入页面时自动统计。

### 2.10 互评、收藏与举报（W5 上线）

**交易互评**：订单完成后，「我的订单 → 已完成」会出现「评价对方」按钮：
- 1-5 星 + 选填评语（≤500 字），一单一人只能评一次；
- 对方给你评价后你会在消息中心收到通知；
- 「我的 → 我的评价」查看收到的 / 我发出的全部评价（带拍品与星级）。

**收藏拍场**：详情页右上角心形按钮即可收藏 / 取消，收藏后可在「我的 → 我的收藏」统一查看（显示当前价、状态与剩余时间），点击直达详情页。

**举报**：详情页卖家信息右侧「举报」入口，填写理由（必填）提交；同一对象不能重复举报；管理员核实后：
- **属实**：被举报方（拍品举报=卖家）信用分 -20，双方均收到处理结果通知；
- **不属实**：驳回并通知举报人。

### 2.11 个人中心

「我的」页提供：完善资料、我发布的、我的出价、我的订单、钱包流水（虚拟余额变动明细）、信用分明细、我的收藏、消息中心、我的评价。

### 2.12 修改资料：头像 / 昵称 / 手机号（隐私合规）

入口：「我的 → 完善资料」。头像/昵称/手机号在登录时已采集，这里用于后续修改。

| 项目 | 操作 | 说明 |
|---|---|---|
| 头像 | 点头像 → 选择微信头像或相册图片 | 选完自动上传到服务器保存，未点「保存」前不会写入资料 |
| 昵称 | 在昵称框填写 | 可使用微信昵称建议；微信会在输入完成后做内容安全检测，未通过会清空 |
| 手机号 | 点「一键填入微信绑定的手机号」→ 确认授权 | 由微信下发动态令牌，服务端换取号码 |
| 保存 | 点「保存资料」 | 保存后「我的」页立即显示新头像昵称 |

**隐私授权弹窗**：首次使用涉及隐私的组件时，微信会要求先同意《用户隐私保护指引》，本系统会弹出说明卡片：
- 点「同意并继续」才启用头像选择、昵称建议与手机号授权；
- 点「暂不同意」仍可继续逛拍场，但这三项暂时不可用，之后回到登录卡片或「我的 → 完善资料」重新同意即可；
- 卡片内可点开官方《用户隐私保护指引》全文。系统不会默认勾选、不会静默获取、也不会因拒绝而影响浏览。

> 手机号是账号识别凭证：同一手机号在任何微信上登录都进入同一账号；不对外公开、不写服务端日志。

## 三、管理员使用手册

### 3.1 进入管理端

入口：小程序「我的 → 管理员审核」。

默认管理员账号（演示环境）：

| 用户名 | 密码 |
|---|---|
| admin | admin123 |

> 管理员身份与普通用户身份相互独立（独立 token），互不影响。

### 3.2 拍品审核（核心职责）

1. 登录后看到**待审核列表**（提交时间从早到晚，避免积压）；
2. 点击任意一条进入审核详情：查看图集、卖家、分类、成色、起拍价、加价幅度、保证金、时长、描述；
3. 二选一：
   - **通过并开拍**：确认后拍卖**立即开始**，时长从当前时刻起算，拍品进入大厅；
   - **驳回**：必须填写理由（卖家会看到），拍品回到卖家处，修改后可重新提交。

**审核建议**（保证平台内容质量）：
- 图片与描述不符、疑似违禁品（药品、贵重数码无凭证等）→ 驳回；
- 起拍价明显不合理 → 提示卖家调整（驳回理由中说明）；
- 描述含联系方式绕过平台交易 → 驳回。

### 3.3 Web 管理后台（W4 上线）

除小程序内的审核分包外，系统另提供 **Vue3 + Element Plus** 的浏览器端管理后台，适合在电脑上批量处理。
启动方式（详见 `admin/README.md`）：后端启动后执行 `cd admin && npm install && npm run dev`，浏览器打开 `http://localhost:5173`，用同一管理员账号登录。

五个功能页：

| 页面 | 能力 |
|---|---|
| **数据看板** | 注册用户数、拍品总数、待审核数、进行中/已成交/流拍场次、已成交订单数、成交总额（元）；拍卖状态分布条形图、按真实类目的成交分布占比 |
| **拍品审核** | 待审核列表（含首图预览），点击标题看完整描述，一键「通过」（立即开拍）或「驳回」（理由必填）；顶部可刷新 |
| **用户管理** | 按昵称搜索 + 分页；显示 openid、余额、信用分（分色标签）、状态；一键**封禁 / 解封**（封禁后无法登录与出价） |
| **拍卖监控** | 按状态 Tab 切换（待开始/进行中/结算中/已成交/流拍/已取消），查看当前价、出价次数、**防狙击延时次数**、起止时间 |
| **订单查询** | 按状态过滤（待交割/已完成/违约取消），查看订单号、买卖双方 ID、成交价、交割方式与地点、创建与完成时间 |
| **举报处理**（W5） | 按状态过滤（待处理/已核实/已驳回），查看被举报方与理由；「核实扣分」= 被举报方信用 -20 并通知双方，「驳回」= 通知举报人；处理说明双方可见 |

> 后台所有请求携带管理员 token，后端按 `/api/v1/admin/**` 路径前缀强制校验管理员身份；普通用户 token 无法访问后台接口。

## 五、常见问题（FAQ）

**Q1：拍卖结束后我怎么知道结果？**
拍卖状态变为「已成交/已流拍」，可在「我的出价」「我发布的」查看；中标双方会收到站内通知。

**Q2：出价被拒绝了，为什么？**
常见原因：①出价低于「当前价 + 加价幅度」；②你已是最高出价者，不能自己超自己；③拍卖已结束；④信用分低于 60 或余额不足以冻结保证金。系统提示会说明具体原因。

**Q3：图片上传失败？**
检查图片格式（jpg/png/webp）与大小（≤2MB）；发布页已自动压缩，一般无需手动处理；仍失败请检查网络后重试。

**Q4：审核要多久？**
演示环境即时处理；实际运营建议承诺 24 小时内。

**Q5：虚拟余额用完了怎么办？**
虚拟余额仅用于保证金冻结，不参与真实交易；余额不足时无法出价，正常完成交易会获得奖励。

**Q6：管理员和普通用户可以是同一个微信号吗？**
可以。管理员登录后 token 独立存储，不影响普通用户登录态。

**Q7：点击「帮我估个价」返回的是规则估价而不是 AI？**
服务端未配置大模型 Key（或调用超时/限流）时会自动降级为规则估价，卡片徽标显示「智能估价」而非「AI 估价」。配置 `AI_PRICE_KEY` 后重启服务端即切换为大模型通道，无需改代码。

**Q8：小程序登录一直失败 / 提示「微信服务暂不可用」？**
先看后端日志（`server/server-run.log`）：
- 若 `code2session 失败` 且 `invalid code`（40029）：code 一次性已用完，重新登录即可；`invalid appsecret`（40125）检查 AppSecret；网络超时则检查本机能否访问 `api.weixin.qq.com`。
- 若日志里 `code2session 成功`、`access_token 成功`，但 `换取手机号` 报 **412 Precondition Failed**：这是 Spring Boot 3.2 / Spring Framework 6.1 不缓冲请求体、POST 缺 `Content-Length` 导致微信网关拒绝，**已在 `RedisConfig` 用 `BufferingClientHttpRequestFactory` 修复**，重启服务端即可。
- 若日志里**已经有 openid、但 errcode 是 null**，说明微信其实返回成功了——微信成功响应不带 errcode 字段，旧版后端曾把它误判为失败（已修复，现以 openid 是否存在为判据），重新点一次登录即可。

**Q9：登录时弹出隐私授权，选了头像却没变化？**
首次使用头像 / 昵称 / 手机号组件前需先同意《用户隐私保护指引》。登录页现在也会弹这个授权卡（以前只有「完善资料」页有）。若点了「先不同意」，`chooseAvatar` 等组件会降级或不可用，点资料区里的「还没同意隐私指引，点此重新查看」可再次打开。另外小程序后台尚未配置并审核通过隐私指引时，这些组件会被微信直接禁用——演示环境请在 MP 后台「设置 → 服务内容声明 → 用户隐私保护指引」中声明「昵称、头像、手机号」并等待审核通过，详细步骤见《项目启动教程》8.1 节。

**Q9+：点「微信一键授权手机号」提示 errno 112 / 「api scope is not declared in the privacy agreement」？**
这是**平台层校验**，不是前端 bug：MP 后台《用户隐私保护指引》没有声明「手机号」采集类型，微信直接禁用了 `getPhoneNumber` 接口。前端弹窗解决不了它。
- **答辩演示（当前配置）**：`app.json` 的 `__usePrivacyCheck__` 已设为 `false`，开发版/体验版可跳过隐私校验直接授权手机号，按此配置即可正常演示。
- **将来提审上线**：需按《项目启动教程》8.1 节的清单在 MP 后台声明「手机号 / 昵称 / 头像」三项（入口在**左下角头像 → 账号设置 → 服务内容声明**，不在左侧「设置」里；若提示先设类目，先点「前往设置」补一个类目），审核通过后等约 5 分钟、清缓存重开项目，并把 `__usePrivacyCheck__` 改回 `true`。注意未发布上线的小程序在账号设置页声明不生效，详见 8.1 节。

**Q10：登录时授权手机号提示失败或「体验额度已用完」？**
手机号是登录必填项，未授权则无法完成新用户建号。① 提示「体验额度已用完」是手机号快速验证组件的 1000 次体验额度耗尽，需到 MP 后台购买资源包；② 提示「微信服务暂不可用」多为 AppSecret 配置、`access_token` 获取或网络问题，看后端日志 `server/server-run.log`；③ 动态令牌 5 分钟有效且只能用一次，超时请重新点一次授权按钮；④ errno 112 见上面的 Q9+。

## 七、学校认证与本校拍场（2026-11-21 新增）

**Q11：为什么别人学校的拍品我看不到？**
本项目按学校隔离拍品。游客（未登录）能看到全部拍品浏览；登录并**通过学校认证**后，拍场只显示本校拍品，详情、出价、收藏也只限本校，跨校访问会提示「该拍品不属于你的学校」。

**Q12：怎样完成学校认证？**
进入 `我的 → 学校认证`，选择学校（河南理工/河南职院/郑大/河大/河南财大/华水），填写**真实姓名、学号**并上传**学生证照片**，点击「提交审核」。管理员在小程序「管理员审核 → 认证审核」或 Web 后台「学校认证审核」中核对通过后，认证才会生效。

**Q13：提交后为什么还不能发布/出价？**
认证状态为「审核中」时暂不开放发布与交易。审核通过后，回到「我的」页会自动刷新状态，首页也会切成本校拍场。若列表没变化，下拉刷新即可。

**Q14：被驳回了怎么办？**
「我的 → 学校认证」会显示驳回理由。按要求修改姓名/学号或重新拍摄学生证后，点「修改后重新提交」即可再次进入待审。

**Q15：换学校需要重新认证吗？**
需要。提交新学校的申请后，旧学校身份会立即失效并进入待审，通过后才能进入新学校的拍场；同一学校重复提交不会重复审核。

**Q16：填写的姓名、学号、学生证会保存到哪里？**
提交时即写入用户资料表（`t_user`）做持久化，管理员审核通过后再以审核结果回写一次。你可以在「我的 → 完善资料」底部的「校园认证」卡片里看到已保存的姓名、学号、学校和状态。认证申请表仍会保留审核记录（审核人、驳回理由、审核时间）。
