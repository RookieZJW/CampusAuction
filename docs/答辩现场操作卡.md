# 答辩现场演示操作卡（真机调试方案）

> 方案：不买服务器、不用域名、不备案。笔记本跑后端 + 手机真机调试扫码，评委扫你的调试码即可用。
> 前提：后端已启动、手机与电脑连**同一个 WiFi**、开发者工具已打开项目。

---

## 一、演示前 10 分钟准备

### 1. 查电脑局域网 IP

按 `Win + R` → 输入 `cmd` → 回车 → 输入：

```
ipconfig
```

找到「无线局域网适配器 WLAN」下的 `IPv4 地址`，例如 `192.168.3.228`。
（换教室/换 WiFi 后 IP 会变，必须重查并更新 `miniprogram/utils/config.js` 的 `LAN_IP`。）

### 2. 改小程序配置

打开 `miniprogram/utils/config.js`，确认两处：

```js
const USE_LAN_IP = true          // 答辩时改为 true
const LAN_IP = '192.168.3.228'   // 改成上一步查到的 IP
```

保存后回到开发者工具，点「编译」刷新。

### 3. 确认后端在跑

浏览器打开 `http://localhost:8080/api/v1/categories`，返回 `{"code":0,...}` 即正常。
没启动则：

```
cd /e/campus-auction/server
mvn -q -o spring-boot:run
```

### 4. 勾选不校验域名（关键）

微信开发者工具右上角 →「详情」→「本地设置」→ 勾选：

> ☑ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

### 5. 确认微信确认弹窗配置

开发者工具 →「详情」→「本地设置」→ 确认「**预览/真机调试时显示「本次登录使用到的...」**」相关体验配置不影响演示即可，不必改。

---

## 二、演示时怎么扫

1. 开发者工具点「**真机调试**」（**不是**「预览」）。
   - 真机调试：绕过域名校验，走本机后端 ✅
   - 预览：会校验合法域名，没有备案域名就加载不出数据 ❌
2. 生成的二维码在开发者工具面板上，让评委用微信扫。
3. 评委手机进入小程序 → 弹登录卡片 → 填昵称 → 授权手机号 → 勾协议 → 登录。
4. 「我的」页显示真实头像、昵称、手机号。
   - 头像走 base64 本地显示（真机 image 组件会拦截 http+纯IP 外链），换 WiFi / IP 变化都不影响，无需额外配置。

> 评委手机若提示「不在合法域名列表」，说明勾选项没生效或点成了「预览」，回到第 4、5 步检查。

---

## 三、演示后收尾

把 `miniprogram/utils/config.js` 改回：

```js
const USE_LAN_IP = false
```

否则下次用模拟器开发时，本机若不在那个 IP 上会连不上后端。

---

## 四、常见故障速查

| 现象 | 原因 | 解决 |
|---|---|---|
| 手机显示数据为空 / 加载失败 | 点成了「预览」而非「真机调试」 | 改点「真机调试」重扫 |
| 提示 `url not in domain list` | 没勾「不校验合法域名」 | 回到准备步骤 4 |
| 请求超时 | 手机和电脑不在同一 WiFi | 连同一个 WiFi；关掉手机的流量 |
| 请求超时（WiFi 正确） | LAN_IP 写错或 IP 变了 | 重新 `ipconfig` 查并更新 config.js |
| 后端接口 502/拒绝 | 后端没启动或端口被占 | 浏览器测 `localhost:8080`，重启后端 |
| 真机登录报 3008 | code 一次性/网络问题 | 重新点登录；看 `server/server-run.log` |

## 五、关于已有的域名

你已有域名但没有服务器，在真机调试方案下**用不上**——域名只有在「公网部署 + HTTPS + 合法域名配置」时才需要。

将来若要试审或公网演示，再买一台轻量服务器（2核4G，约 200-400 元/年），把域名解析到服务器、配 HTTPS 和 Nginx 反代即可。域名若尚未 ICP 备案，还需先备案（7-20 工作日），备案主体须与小程序主体一致。

> 提醒：正式上架时「拍卖」属限制类目，经营性网络拍卖需《拍卖经营批准证书》，个体工商户主体不具备申请资格。以微信官方最新规则为准。

## 六、学校认证隔离演示（2026-11-21 新增）

当前 8 件拍品全部归属河南理工。用「改认证学校」来演示隔离效果，不需要改数据库：

1. 打开小程序 →「我的」→ 名片上显示「河南理工 · 本校拍场」，学校认证入口显示「河南理工」。
2. 回「拍场」首页：能看到本校在拍的拍品。
3. 进「我的」→「学校认证」→ 改选「郑州大学」→ 确认认证。
4. 回「拍场」首页：列表自动刷新，拍品变空（郑大本校暂无拍品）——说明只看到本校的。
5. 再进「我的」→「学校认证」→ 改回「河南理工大学」→ 确认，拍品恢复。

> 演示要点：认证后列表按本校过滤；跨校拍品即使直接打开详情也会被拒（提示「该拍品不属于你的学校」）；未登录游客不受限制，仍能看到全部。
> 答辩结束记得把账号认证改回河南理工，保持默认状态。
