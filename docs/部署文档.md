## 一、部署架构

```
                     微信小程序（学生端）
                            │
                     Vue3 Web 管理后台
                            │ HTTPS
┌───────────────────────────▼───────────────────────────┐
│  Nginx（443/80）                                        │
│  ├── 主域名    : /api/**、/uploads/** → Spring Boot :8080 │
│  ├── admin子域名: / → Vue 构建产物（history 回落）        │
│  │                /api/**、/uploads/** → Spring Boot :8080 │
└───────────────────────────┬───────────────────────────┘
                            │
┌───────────────────────────▼───────────────────────────┐
│  Spring Boot 3.2（8080，Docker 容器或 systemd）         │
└──────┬──────────────────┬───────────────┬─────────────┘
       │                  │               │
┌──────▼──────┐   ┌───────▼──────┐  ┌─────▼──────────┐
│ MySQL 8.0   │   │ Redis 7      │  │ 外部服务         │
│ 3306 仅内网 │   │ 6379 仅内网  │  │ 微信API/AI API  │
└─────────────┘   └──────────────┘  └────────────────┘
```

**两种部署形态**：

| 形态      | 适用      | 说明                                                   |
| ------- | ------- | ---------------------------------------------------- |
| 开发/演示环境 | 本机、答辩演示 | 无需域名与 Nginx，小程序勾选「不校验合法域名」直连 `http://localhost:8080` |
| 生产环境    | 正式上线    | 需云服务器 + 已备案域名 + HTTPS 证书 + Nginx（**本毕设仅演示，不上线**）     |

## 三、开发/演示环境部署（Windows，当前实际环境）

> 这是**答辩演示用的标准路径**，10 分钟可完成。

### 3.1 获取代码

```bash
# 已在本机 E:/campus-auction；如换机器：
git clone <仓库地址> E:/campus-auction
# 或解压 zip 包
```

### 3.2 初始化数据库

```bash
mysql -u root -p < E:/campus-auction/sql/init.sql
```

执行后自动完成：创建库 `campus_auction`（utf8mb4）→ 14 张表 → 初始数据（7 个分类、管理员 admin/admin123）。

**验证**：

```sql
USE campus_auction;
SHOW TABLES;          -- 应有 14 张 t_ 前缀表
SELECT COUNT(*) FROM t_category;   -- 7
```

### 3.3 启动 Redis

```bash
# 本机实际安装位置（无配置文件，默认参数启动）
D:\Redis-8.6.4\redis-server.exe --port 6379

# 验证
D:\Redis-8.6.4\redis-cli.exe ping   # 返回 PONG
```

> ⚠️ 在 Git Bash 中给 exe 传 `D:/xxx.conf` 这类路径参数会被 MSYS 改写导致启动失败——**要么不带参数，要么用 PowerShell 启动**。

### 3.4 配置并启动服务端

**第一步：写本机私密配置**（文件已在 .gitignore 中，不会提交）

编辑 `E:/campus-auction/server/src/main/resources/application-local.yml`：

```yaml
spring:
  datasource:
    password: <你的MySQL root密码>

wx:
  # 不接真实微信登录时保持 true（openid 用模拟值，无需 AppSecret）
  mock: true
  # 需要真实微信登录时改为 false 并补全：
  # appid: wx4aa1de34c361be17
  # secret: <你的AppSecret>
```

**第二步：启动**

```bash
cd E:/campus-auction/server
mvn spring-boot:run
```

首次启动会下载依赖（约 3-5 分钟），之后启动约 10 秒。

**第三步：验证**

- 接口文档：浏览器打开 `http://localhost:8080/doc.html`（Knife4j）
- 冒烟测试：

```bash
# 登录（mock 模式）
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H "Content-Type: application/json" -d '{"code":"test"}'
# 期望返回 {"code":0,...,"data":{"token":"...","balance":10000,...}}

# 分类
curl http://localhost:8080/api/v1/categories
# 拍卖列表
curl "http://localhost:8080/api/v1/auctions?page=1&size=10"
```

### 3.5 配置小程序端

1. 打开微信开发者工具 → 导入项目 → 选择 `E:/campus-auction/project.config.json`；
2. AppID 已配置（`wx4aa1de34c361be17`）；
3. **关键设置**：详情 → 本地设置 → 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**；
4. 编译运行；真机预览：工具栏「预览」扫码（手机上也需开启调试模式）。

### 3.6 启用 AI 定价建议（可选，W5）

AI 估价默认关闭（自动走规则估价）。要启用真实大模型估价，在 `server/src/main/resources/application-local.yml` 追加：

```yaml
ai:
  price:
    enabled: true
    base-url: https://api.deepseek.com   # 换通义千问则改 dashscope 兼容地址
    api-key: sk-xxxx                     # 你的 DeepSeek API Key
    model: deepseek-chat
```

或用环境变量：`AI_PRICE_ENABLED=true`、`AI_PRICE_KEY=sk-xxx`、`AI_BASE_URL`、`AI_MODEL`。

> ⚠️ Key 只放 local.yml（已 gitignore）或环境变量，**严禁写进 application.yml / 提交 git / 出现在小程序前端**。  
> Key 未配、调用超时（8 秒）、限流或返回异常时自动降级为规则估价，接口永不 500——发布页卡片会以「智能估价」徽标提示当前走的是降级通道。

### 3.7 启动 Web 管理后台（开发环境）

前置：Node.js ≥ 18；后端已在 8080 运行。

```bash
cd E:/campus-auction/admin
npm install          # 首次执行，约 1-2 分钟
npm run dev
# 浏览器打开 http://localhost:5173 ，账号 admin / admin123
```

- Vite 已配置 `/api`、`/uploads` 代理到 `http://localhost:8080`，无需处理跨域；
- 登录 token 存浏览器 `localStorage.admin_token`，与小程序端 token 互不影响；
- 生产构建：`npm run build`，产物在 `admin/dist/`，Nginx 部署见 4.7。

## 四、生产环境部署（Linux + 云服务器）

> 毕设不要求上线，本章为论文「系统部署」章节与真实上线预留。

### 4.1 服务器准备

| 项   | 建议                                                  |
| --- | --------------------------------------------------- |
| 规格  | 2 核 4G（演示级）/ 4 核 8G（运营级）                            |
| 系统  | Ubuntu 22.04 LTS / CentOS Stream 9                  |
| 安全组 | 仅放行 80/443；MySQL 3306、Redis 6379、应用 8080 **不对公网开放** |
| 域名  | 已完成 ICP 备案的域名，解析 A 记录到服务器公网 IP                      |
| 证书  | Let's Encrypt 免费证书（certbot 自动续期）或云厂商证书              |

> ⚠️ 小程序 `request` 合法域名强制要求 **HTTPS + 已备案域名**，这一步无法绕过（开发版/体验版除外）。

### 4.2 安装基础组件

```bash
# JDK 17
apt install -y openjdk-17-jdk

# MySQL 8（或使用云数据库 RDS）
apt install -y mysql-server
mysql_secure_installation

# Redis 7（或使用云 Redis）
apt install -y redis-server
# 生产必改：/etc/redis/redis.conf 中设置 requirepass <强密码>

# Nginx
apt install -y nginx
```

### 4.3 初始化数据库

```bash
mysql -u root -p < /opt/campus-auction/sql/init.sql
# 生产环境建议：单独建应用账号并只授权 campus_auction 库
CREATE USER 'auction'@'localhost' IDENTIFIED BY '<强密码>';
GRANT ALL PRIVILEGES ON campus_auction.* TO 'auction'@'localhost';
FLUSH PRIVILEGES;
```

### 4.4 构建服务端

```bash
cd /opt/campus-auction/server
mvn -DskipTests package
# 产物：target/campus-auction-server-0.1.0.jar
```

### 4.5 环境变量清单（生产）

密钥与敏感值**全部走环境变量，不写进代码与配置文件**：

| 变量                 | 说明                       | 示例                           |
| ------------------ | ------------------------ | ---------------------------- |
| `MYSQL_USER`       | 数据库账号                    | auction                      |
| `MYSQL_PASSWORD`   | 数据库密码                    | 强密码                          |
| `REDIS_HOST`       | Redis 地址                 | 127.0.0.1                    |
| `REDIS_PORT`       | Redis 端口                 | 6379                         |
| `WX_APPID`         | 小程序 AppID                | wx4aa1de34c361be17           |
| `WX_SECRET`        | 小程序 AppSecret            | 微信公众平台获取                     |
| `JWT_SECRET`       | JWT 签名密钥（≥32 字符随机串）      | `openssl rand -base64 48` 生成 |
| `UPLOAD_DIR`       | 图片存储绝对路径                 | /opt/campus-auction/uploads  |
| `AI_PRICE_ENABLED` | 启用 AI 定价（默认 false 走规则估价） | true                         |
| `AI_PRICE_KEY`     | 大模型 API Key（DeepSeek 等）  | sk-xxxx                      |
| `AI_BASE_URL`      | OpenAI 兼容接口地址            | <https://api.deepseek.com>   |
| `AI_MODEL`         | 模型名                      | deepseek-chat                |

> 微信侧还需在公众平台「开发管理 → 服务器域名」配置 `request 合法域名` 为 `https://你的域名`。

### 4.6 以 systemd 托管服务

`/etc/systemd/system/campus-auction.service`：

```ini
[Unit]
Description=Campus Auction Server
After=network.target mysql.service redis-server.service

[Service]
WorkingDirectory=/opt/campus-auction
ExecStart=/usr/bin/java -jar server/target/campus-auction-server-0.1.0.jar \
  --spring.profiles.active=prod
Environment=MYSQL_USER=auction
Environment=MYSQL_PASSWORD=<强密码>
Environment=REDIS_HOST=127.0.0.1
Environment=WX_APPID=wx4aa1de34c361be17
Environment=WX_SECRET=<secret>
Environment=JWT_SECRET=<随机密钥>
Environment=UPLOAD_DIR=/opt/campus-auction/uploads
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now campus-auction
systemctl status campus-auction
journalctl -u campus-auction -f   # 看日志
```

### 4.7 Nginx 配置

`/etc/nginx/conf.d/campus-auction.conf`：

```nginx
server {
    listen 80;
    server_name 你的域名;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name 你的域名;

    ssl_certificate     /etc/letsencrypt/live/你的域名/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/你的域名/privkey.pem;

    client_max_body_size 10m;   # 与服务端 multipart 上限匹配

    # 业务接口与上传文件 → Spring Boot
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;   # 上传接口按 Host 生成完整 URL，必须透传
    }
}

# Web 管理后台（Vue3 单页应用，独立子域名，避开 history 路由与 base 路径问题）
server {
    listen 443 ssl http2;
    server_name admin.你的域名;

    ssl_certificate     /etc/letsencrypt/live/admin.你的域名/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/admin.你的域名/privkey.pem;

    client_max_body_size 10m;

    # 前端静态资源
    location / {
        root /opt/campus-auction/admin/dist;
        try_files $uri $uri/ /index.html;   # history 路由必须回落到 index.html
    }

    # 后台接口同源转发，前端 axios baseURL 写 /api/v1 即可
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    location /uploads/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }
}
```

> 也可把后台挂在主域名的 `/admin/` 子路径，但需要同时设置 Vite `base: '/admin/'` 与 `createWebHistory('/admin/')`，  
> 否则刷新页面会出现 404。毕设演示用独立子域名最省事。

```bash

```

### 4.9 Docker Compose 一键部署（可选）

```yaml

    build: ./server

    volumes: ["./nginx.conf:/etc/nginx/conf.d/default.conf", "./certs:/etc/letsencrypt"]
    depends_on: [app]
volumes:
  dbdata:
```

## 五、常见部署问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 小程序请求全部失败 | 未勾选「不校验合法域名」 | 详情→本地设置勾选；生产则检查合法域名配置 |
| 服务端启动报 `Access denied for user` | MySQL 密码不对 | 核对 application-local.yml / MYSQL_PASSWORD 环境变量 |
| 报 `Communications link failure` | MySQL 未启动或地址端口不对 | `netstat -an \| grep 3306`；检查 datasource.url |
| 登录返回 3008 微信登录失败 | wx.mock=false 但 AppSecret 错误/未配 IP 白名单 | 公众平台核对 Secret；检查 code 是否已使用（code 一次性） |
| 图片上传 413 | Nginx `client_max_body_size` 过小 | 调大到 10m 并 reload |
| 图片能传但回读 404 | Nginx 未透传 Host / UPLOAD_DIR 与映射不一致 | 检查 `/uploads/` 的 proxy_set_header Host 与 Spring 的 addResourceLocations |
| 定时结算不跑 | 应用未启动或时区不对 | 确认 JVM 时区 `Asia/Shanghai`（application.yml 已配 jackson，JVM 需 `-Duser.timezone=Asia/Shanghai`） |
| Redis 连接失败 | Redis 未启动/密码未配 | `redis-cli ping`；核对 data.redis 配置 |
| 中文乱码 | 表/库字符集不是 utf8mb4 | init.sql 已指定；旧库需 `ALTER DATABASE ... CHARACTER SET utf8mb4` |
| 后台页面空白、控制台报 404 | history 路由未回落 index.html | Nginx 加 `try_files $uri $uri/ /index.html` |
| 后台能登录但所有列表 401/2002 | 部署在子路径但 axios baseURL 仍为 `/api/v1` | 保持同源部署，或改 `src/api/request.js` 的 baseURL |
