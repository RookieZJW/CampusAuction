### 已实现的基础设施

统一响应 Result/ResultCode、全局异常处理、JWT 工具（HS256）、登录拦截器（Bearer 头，白名单放行 /auth/login 与文档路径）、MyBatis-Plus 分页插件、RedisTemplate（String key + JSON value）、RestTemplate、Knife4j（http://localhost:8080/doc.html）、CORS。

### 前端约定

token 存 `wx.setStorageSync('userInfo')`；请求封装 `utils/request.js` 自动注入 Bearer 头、2001/2002 自动清登录态并跳登录页；`utils/config.js` BASE_URL=http://localhost:8080（开发者工具须勾选「不校验合法域名」）。

### wx API 已用

`wx.login`、`wx.request`、`wx.setStorageSync`、`wx.showToast`、`wx.showModal`、`wx.switchTab`、`wx.navigateTo`（首页倒计时 setInterval，onUnload 已清理）
