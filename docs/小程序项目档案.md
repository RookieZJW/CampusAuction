**鉴权设计**：用户 token subject=openid；管理员 token subject="admin:{id}"；拦截器按 `/api/v1/admin/**` 路径前缀强制管理员身份（用户 token 访问返回 2003，已验证）。浏览类接口（categories/auctions 列表与详情）设为公开，满足"未登录可浏览"。

### 已实现基础设施

统一响应/全局异常（含 fail(ResultCode,msg) 重载）、JWT、双身份拦截器、MyBatis-Plus 分页、RedisTemplate、RestTemplate、Knife4j（/doc.html）、CORS、上传静态资源映射 `/uploads/**`、图片类型/大小校验（UUID 文件名防路径穿越）、列表 VO 批量查询避免 N+1、昵称脱敏。

### 前端约定

`utils/request.js` 支持 `token` 参数覆盖（管理员场景）；图片上传走 `wx.uploadFile`（Bearer 头）；发布页元转分 `Math.round(yuan*100)`；管理员 token 独立存 `adminToken` key。

### wx API 已用

wx.login、wx.request、wx.uploadFile、wx.chooseMedia、wx.compressImage(720px/80%)、wx.previewImage、wx.showModal(editable 驳回理由输入，基础库≥2.17.1，以官方文档核实)、存储类、导航类、倒计时 setInterval（onUnload 清理）
