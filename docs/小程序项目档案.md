### W3 核心机制（论文素材，全部实测）

1. **双层出价校验**：Redis Lua 原子脚本（`auction:bid:{id}` HASH + check-and-set）→ MySQL 乐观锁（`WHERE version=? AND current_price<?`，冲突重试 3 次）；Redis 不可用自动降级 DB 单层；落库失败回写 Redis。
2. **防狙击**：末 5 分钟出价 → endTime=now+2min，extend_count 上限 3（实测 extended=true 返回）。
3. **保证金**：每场每用户首次出价冻结 1000 分（SQL 原子扣减 `balance>=deposit` 防透支），流水入 t_account_log；结算时落标者 UNFREEZE（实测 user4: 9000→10000）。
4. **定时结算**：@Scheduled 30s 扫描 + Redis SETNX 分布式锁 + CAS(ONGOING→SETTLING) + t_order.auction_id 唯一索引三重幂等；实测自动 FINISHED + 建单 AU202611131924565563 + 通知双方。
5. **实时刷新**：/live 只回 4 字段；前端 3 秒局部 setData + 振动反馈；onHide 暂停轮询。
